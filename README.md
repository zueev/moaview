# 모아뷰

전국 배송형 체험단과 서울 방문 체험단을 모아 보는 개인 대시보드입니다.

## GitHub에서 수정하기

저장소에서 수정할 파일을 열고 연필 버튼으로 편집한 뒤 Commit changes를 누르세요. 전체 편집기는 저장소 화면에서 키보드의 마침표(.)를 누르면 열립니다. main에 저장하면 Actions가 사이트를 다시 배포합니다.

- 화면과 문구: app/desk.tsx, app/feed.tsx
- 디자인과 여백: app/globals.css
- 사이트 수집: lib/direct-feed.ts, lib/twentynine.ts
- 카테고리: lib/categories.ts
- 모바일 신청 링크: app/campaign-link.tsx

## 기능

29CM 우선 · 뷰티/패션 분류 · 사이트별 필터 · 검색과 경쟁률 정렬 · 관심 저장 · 신청 완료 표시 · 당첨 후 할 일과 마감 관리.

신청은 원본 사이트에서 직접 합니다. 29CM은 모바일 앱 링크와 웹 대체 링크를 제공합니다. 신청 후 돌아와 신청 완료로 표시하세요. 당첨도 직접 상태를 변경하면 할 일이 생성됩니다.

## 데이터와 저장

공개 모집 목록을 GitHub Actions에서 6시간 간격으로 수집합니다. 플랫폼별 공개 목록 일부만 연결되어 있으며 사이트 안에 수집 범위와 실패 상태를 표시합니다. GitHub 예약 실행은 지연될 수 있습니다. 새로고침은 마지막 배포된 데이터를 다시 읽습니다.

공개 사이트와 소스에는 개인 신청 기록이 없습니다. 관심·신청·할 일은 사용하는 브라우저의 localStorage에만 저장됩니다. 기기 간 자동 공유되지 않으며 브라우저 데이터를 지우면 사라집니다. 기존 사이트 기록 이전과 내보내기·가져오기는 포함하지 않습니다.

## 로컬 실행

Node.js 22 이상에서 npm ci, npm run collect, npm run dev 순서로 실행합니다. npm run build로 배포 파일을 생성합니다.
